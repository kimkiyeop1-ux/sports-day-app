# 🏫 체육대회 원앱 — 우리 학교에서 쓰기 (다른 학교 선생님용 안내)

체육대회 원앱은 **무료**이고, 우리 학교 데이터는 **우리 학교 Firebase에만** 저장됩니다.
다른 학교와 섞이지 않으며, 앱을 만든 사람도 우리 학교 데이터를 볼 수 없습니다.
학생 개인정보는 다루지 않습니다(단위는 '학년-반'만 사용).

- 앱 주소(안정판): `https://kimkiyeop1-ux.github.io/sports-day-app/`
- 준비 시간: 약 15분 (Google 계정만 있으면 됩니다. 카드 등록 없음. 어려운 설정은 앱이 하나씩 확인해 줍니다)

- 누구나 무료로 쓰고, 고치고, 다른 학교에 나눠 줄 수 있습니다(MIT 라이선스).

| 기능 | 상태 |

## 1단계. Firebase 프로젝트 만들기 (3분)

1. https://console.firebase.google.com 접속 → 학교 업무용 Google 계정으로 로그인
2. **프로젝트 만들기**(또는 **새 프로젝트**) → 이름 입력(예: `sports-day-우리학교`) → 나머지는 **계속**만 누르기

## 2단계. 앱의 [학교 연결] 화면 따라 하기 (10분)

1. 앱 주소 접속 → **🏫 학교 연결**
2. **1번 칸**에 방금 만든 프로젝트 이름 입력 → **2번 [연결 정보 화면 열기]** → 맨 아래 `firebaseConfig` 글 복사 → 붙여넣기 → **[연결하기]**
3. 그러면 앱이 데이터베이스·보안 규칙·로그인 설정·사이트 주소 허용을 **직접 확인해 ✅/❌로 보여 줍니다.**
   ❌인 것만 그 옆 버튼을 누르면 Firebase의 **정확한 설정 화면이 열립니다.** 짧은 안내대로 하고 앱으로 돌아오면 자동으로 다시 확인합니다.
4. 모두 ✅가 되면 **[관리자 화면으로]** → Google 로그인 → **[이 계정을 관리자로 등록]** (처음 한 명만)

> 앱이 업데이트되어 관리자 화면에 '보안 규칙 업데이트가 필요합니다'가 뜨면, 학교 연결 화면에서 ❌ 보안 규칙의 버튼 두 개(규칙 복사 → 규칙 화면 열기)만 다시 하면 됩니다.

## 3단계. 우리 학교 대회 설정

- 관리자 → **[샘플 설정으로 시작]** 후 **대회 설정** 화면에서 학급·종목·배점·시나리오를 우리 학교에 맞게 고치거나,
- 계획서를 바탕으로 만든 **설정 JSON 파일**을 [대회 설정 → 파일 → 불러오기]로 넣습니다.
- 설정 파일 형식: 저장소의 `configs/sample-2026.json` 참고

## 다른 기기 연결

- 전광판 노트북, 심판 선생님 폰에는 **학교 연결 화면의 링크**를 보내 주세요. 링크로 열면 자동으로 우리 학교에 연결됩니다.

## 자주 묻는 질문

**Q. 정말 무료인가요?**
카드 등록이 없는 무료(Spark) 요금제는 한도를 넘어도 요금이 청구되지 않습니다(그날 사용만 멈춤). 체육대회 하루 사용량은 한도보다 훨씬 적습니다.

**Q. 관리자를 바꾸거나 한 명 더 추가하고 싶어요.**
Firebase 콘솔 → Firestore Database → 데이터 → `meta` → `admins` → `uids` 목록에 새 사람의 UID를 추가하세요. (UID는 그 사람이 관리자 화면에 로그인하면 표시됩니다)

**Q. 앱이 업데이트되면 대회 중에 바뀌나요?**
공유 주소는 '안정판'이라 검증된 업데이트만 반영됩니다. 그래도 대회 당일 불안하면 저장소를 복사(fork)해 우리 학교 전용 사이트로 운영할 수 있습니다(README의 '방법 2').

**Q. 내년에도 쓰려면?**
대회 설정에서 대회 ID(예: `2027-우리중`)를 바꿔 새 설정을 저장하면 새 대회가 시작되고, 작년 데이터는 그대로 남습니다.
